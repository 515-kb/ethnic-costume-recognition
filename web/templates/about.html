技术说明

项目技术架构、使用说明与 API 文档

技术架构

后端框架

Flask 3.0 — 轻量级 Python Web 框架，负责页面渲染、文件上传、API 接口和静态资源服务。

AI 引擎

Qwen-VL-Plus — 阿里云通义千问多模态大模型，通过 DashScope API 调用，负责图像理解和服饰分类。

前端界面

Bootstrap 5 + 原生 JavaScript，深色主题设计，响应式布局，支持拖拽上传和实时结果展示。

识别流程
1. 图片上传
用户上传服饰图片
2. Base64 编码
图片转为 Base64 格式
3. API 调用
调用 Qwen-VL-Plus API
4. 结果返回
解析 JSON 并展示结果

快速开始

1
克隆项目并安装依赖

从 GitHub 克隆仓库，使用 pip 安装 Python 依赖

# 克隆项目 git clone https://github.com/your-username/ethnic-costume-recognition.git cd ethnic-costume-recognition # 安装依赖 pip install -r requirements.txt
2
配置 API Key

在阿里云百炼平台获取 API Key，设置为环境变量

# Windows (PowerShell) $env:DASHSCOPE_API_KEY = "your-api-key-here" # Windows (CMD) set DASHSCOPE_API_KEY=your-api-key-here # Linux / macOS export DASHSCOPE_API_KEY="your-api-key-here"
3
启动服务

运行启动脚本，浏览器访问即可使用

# 启动 Flask 服务 python web/app.py # 浏览器访问 http://127.0.0.1:5000

API 接口文档

GET /api/health 健康检查

返回服务状态、API 配置状态和支持类别数

GET /api/classes 获取所有类别

返回 55 个民族类别的详细信息（ID、中文名、英文名、拼音）

POST /api/detect 上传图片识别

上传民族服饰图片，返回识别结果。Content-Type: multipart/form-data，字段名: image

# 返回示例 { "predicted_class": "维吾尔族", "predicted_class_en": "Uyghur", "confidence": 0.9456, "analysis": "服饰色彩鲜艳，以红、绿、金为主...", "features": ["艾德莱斯丝绸", "小花帽", ...], "image_url": "/static/uploads/xxx.jpg", "inference_time": 2.35 }
POST /api/detect_sample 识别示例图片

识别内置示例图片。Content-Type: application/json，Body: {"sample_path": "images/samples/xxx.jpg"}

注意事项

  • 本项目使用阿里云 DashScope API 进行图像识别，需要有效 API Key 才能使用识别功能
  • API 调用会产生费用，请参考阿里云计费说明
  • 请勿将 API Key 硬编码在代码中或提交到 Git 仓库，应使用环境变量管理
  • 识别结果由 AI 模型生成，仅供参考，不保证 100% 准确
  • 项目后续计划接入本地训练的 YOLOv5 目标检测模型，实现离线识别
