核心功能

强大的 AI 能力，简单的使用方式

图片智能识别

上传任意民族服饰图片，AI 自动识别所属民族，输出类别、置信度和详细特征分析。

55 个民族覆盖

涵盖汉族及 54 个少数民族的传统服饰，包括维吾尔族、蒙古族、藏族、苗族等常见类别。

深度特征分析

不仅给出识别结果，还从色彩、纹样、款式、配饰等多角度分析服饰的视觉特征。

RESTful API

提供标准 RESTful API 接口，支持图片上传识别和示例图片识别，方便集成到其他应用。

数据集配套

配套 55 类民族服饰目标检测数据集，包含 YOLO 和 VOC 两种标注格式，可用于模型训练。

完全开源

项目基于 MIT 协议开源，代码结构清晰，文档完善，欢迎 Star、Fork 和贡献代码。

快速开始

三步即可启动本地识别服务

1. 克隆项目

从 GitHub 克隆仓库到本地，安装 Python 依赖

2. 配置 API Key

设置 DASHSCOPE_API_KEY 环境变量（阿里云百炼平台获取）

3. 启动服务

运行启动脚本，浏览器访问 http://127.0.0.1:5000 即可使用
